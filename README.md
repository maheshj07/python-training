# Electronics Inventory System

A Flask-based Electronics Inventory System with customer registration, login, product management, and order management.

## Features
- Customer Registration
- Customer Login
- Product Search
- Product Filter
- Order Placement
- Stock Management
- SQLite Database
- Bootstrap Responsive Design

## Technologies Used
- Python
- Flask
- SQLite
- Bootstrap 5
- HTML
- CSS

## Installation

```bash
git clone <repository-url>
cd Electronics-Inventory-System
pip install -r requirements.txt
python app.py
```
